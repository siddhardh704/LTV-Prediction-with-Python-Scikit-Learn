# LTV-Prediction-with-Python-Scikit-Learn
📌 Overview
This project predicts Customer Lifetime Value (LTV) using customer purchase data.
It helps identify valuable customers for better business decisions.

🎯 Objective
Analyze customer data
Predict LTV using machine learning
Segment customers into groups


🛠️ Tools Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib

⚙️ Steps
Load dataset
Clean and preprocess data
Create features (Recency, Frequency, AOV)
Train model (Random Forest)
Predict LTV
Segment customers


📂 Dataset
customer_id
order_id
order_date
order_amount

📈 Output
Predicted LTV values
Customer segments (High / Medium / Low)
CSV file with result
